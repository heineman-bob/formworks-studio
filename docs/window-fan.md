# Window fan design and assembly

## Configure a kit

1. Enter the measured clear opening and any installation clearance to leave around the printed assembly.
2. Choose the number of 140 mm columns and rows. Click each cell to switch between a fan and a solid panel, or use a pattern preset.
3. Place the 80 mm controller column on either side or omit it. The controller occupies the bottom row; matching blanks fill rows above.
4. Let the generator split the remaining width into printable 22–220 mm side panels, or enter exact left and right panel widths. Automatic panels can be placed left, right, or split across both sides.
5. Set wall/body depth from 32–250 mm. The default is 55 mm. Each foam cassette's cut thickness is body depth minus 5 mm, so the 250 mm setting accepts a 245 mm core. Stack cut rigid-foam layers if one board is not thick enough. With output louvers, at least 50 mm is required to leave discharge clearance behind the fan.
6. Set a top rail height of 10–100 mm, or click **Fit sealing rail**. Zero omits the rail and cannot seal the lowered sash. Measure the lower sash thickness and select compressed gasket thickness; the app calculates a 6–50 mm channel width from those values. Set engagement depth (3–20 mm). The channel opens upward across all rail sections, with at least 7 mm below it for rear corner sockets. Apply continuous closed-cell gasket tape along the channel floor and both sides before lowering the sash onto it. Fit sealing rail may reduce the row count when the opening is too short for both rows and a rail.
7. Choose whether to print one bolt-on output louver per fan. Each louver uses four M3 screws in pilot holes in the solid rear outer corners. The fan insertion pocket remains clear. Choose screw length for the actual printed parts.
8. Choose foam cores or sealed air cavities for solid-panel cassettes, and optional removable fan-off covers. Every wide cassette includes a back skin. Set cover depth from 20–80 mm. The interface lists every foam-core cut size and quantity. **Show sealed view** previews the covers installed; **Show running view** hides them.
9. Set dovetail and pin radial clearances independently (0.10–0.80 mm, default 0.30 mm). Print the four fit coupons first: male and female for each joint type.
10. Review the fit, part quantities, and preview, then export the STL kit.

The configurator adjusts counts, clearance, rail height, or the final manual side panel when a choice cannot fit. It shows each adjustment beside the fit summary. The visible **Print list** gives the quantity for every distinct STL; **Inspect in 3D** isolates a component, and **Download STL** exports it individually. **Full configuration** lists the dimensions and row pattern, with a separate JSON download.

Changing the configuration keeps the current 3D zoom and viewing angle. **Recenter** explicitly frames the current assembly or inspected component.

### Preview and mesh cache

The browser displays STL meshes generated by OpenSCAD. The assembly view now requests only its visible parts; fit coupons, magnet spacers, and other off-screen parts load when inspected or shown in the exploded matrix. Up to three needed meshes load concurrently. Browser memory reuses an unchanged mesh while the page stays open.

The server keeps binary STL meshes on disk in `/tmp/window-fan-cache` (a persistent Docker volume). Each part's cache key includes only dimensions that change that part's geometry. Changing opening width, fan count, or the fan/solid layout reuses unchanged fan housings and other shared modules. The disk cache is pruned to `MESH_CACHE_MAX_MB` (default 1024 MiB) at server startup. No database is required for this content-addressed part cache.

`make warm-cache` precomputes up to 24 distinct default meshes for a local server using a small set of reference widths; `python3 app/prewarm.py --max-meshes=8` runs a smaller batch. For Docker, run `docker compose exec configurator python app/prewarm.py --max-meshes=24` so the generated files land in the persistent container volume. This is optional and may take minutes because OpenSCAD renders complex housings. It warms reusable parts, not finished ZIPs. Every user ZIP is assembled from the exact validated configuration.

The opening panel includes example widths of 610, 762, and 914 mm (US references) and 800 and 1000 mm (metric references). These are **starting examples, not fit guarantees**. Andersen publishes 610, 762, and 914 mm as *minimum rough opening* widths for selected double-hung products; Internorm lists 800 and 1000 mm as *masonry opening* widths for selected European basement windows. Neither is the clear opening under the user's sash. Always measure that opening before export. Sources: [Andersen A-Series size chart](https://www.andersenwindows.com/-/media/Project/AndersenCorporation/AndersenWindows/AndersenWindows/files/technical-docs/sizing/sizing-windowswithstormwatch--a-series-hung.pdf), [Internorm window catalog](https://www.internorm.com/fileadmin/internorm/PL-pl/Download/Allgemein/KATALOG_OKIEN_2015-2016.pdf).

The preview can show a double-hung window with its **lower sash seated in the printed top rail**, a horizontal slider, or an outward-opening casement, with frame, glass, and sill context. The double-hung view shows the bottom and side gasket runs; the exported hardware list includes a three-run tape length allowance. These are visual examples. Check the actual sash travel, screens, locks, exterior clearance, and retention before treating a window as compatible. The style selector changes preview geometry only, so switching styles does not regenerate printable meshes.

The assembly preview includes a generic 120 × 120 × 25 mm purchased-fan mock with animated blades, a front control-panel mock, and an ESP32-shaped board in the controller cavity. Click the 3D panel's minus and plus buttons to change speed by 10%, or its center power button to stop and resume. Matching buttons and a slider below the viewer provide the same controls; the display and blade rotation stay synchronized. Starting the preview fan removes any displayed off-cycle covers. **Show internals** hides the controller lid in the preview; orbit to the back to inspect the board. These visual mocks do not create STLs or change the printed kit or electrical configuration.

**Exploded matrix** arranges one copy of every distinct printable STL and every distinct foam cut in separate 3D cells. Each cell says **PRINT** or **CUT** with its quantity; the matching catalog gives names, STL filenames, and foam dimensions. Click a part, its number, or a catalog entry to inspect it alone. Click **Exploded matrix** to return to the whole matrix, or **Assembly** to return to the fitted window layout. The matrix updates when the configuration changes while preserving the current viewing angle and zoom; use **Recenter** to fit a changed matrix on screen.

If the remaining width allows another 140 mm column, the interface offers **Add fan column**. This changes the number of cells; any cell can then be changed to a solid panel.

## Dimensions

- 120 mm nominal fans with 105 mm mounting-hole pitch and approximately 25 mm fan thickness
- Fan and solid cells: 140 × 140 mm; controller column: 80 mm; end caps: 12 mm each
- Wall/body depth: 32–250 mm; exterior louvers project a further 20 mm
- Insulated fan-off cover depth: 20–80 mm, projecting into the room
- Built width: `24 + 140 × columns + controller width + side panel widths`
- Built height: `140 × rows + top rail height`
- Supported opening: 200–4000 mm wide, 140–1200 mm high; up to 20 columns and 8 rows
- Side panels: 22–220 mm each; top rails: 10–100 mm high
- Top rail sash channel: 6–50 mm wide, with 3–20 mm vertical engagement; rail height retains at least 7 mm below the groove
- Row alignment keys: four 4.8 mm pegs near the front and rear corners of modules at least 20 mm wide, with socket diameter `4.8 + 2 × pin clearance` mm. Narrow end caps use two pegs. The dovetail groove uses its own radial clearance.

The fit display reports any unfilled height above the assembly. A zero top gap means the configured assembly covers the usable opening height. The exported `configuration.json` records measured size, clearance, columns, row pattern, panel widths, top rail, and print quantities.

## Airflow path

The fan is a purchased 120 × 120 × approximately 25 mm axial unit, inserted from the outdoor side against the front flange. The revised inlet has a rounded 122 mm mouth converging to a 114 mm throat at the fan frame. The printed room-side guard uses a central hub disk, thin spokes, and three rings instead of wide crossbars. The housing leaves a straight rear plenum behind the fan. The bolt-on rain louver has a 116 mm circular outlet and five shallower, more widely spaced slats; the previous outlet was only 94 mm square before its slats. The web preview shows a dark fan rotor solely to make placement and flow direction visible; it is not an STL or included hardware.

Air enters from the room (negative Y) and exits outdoors (positive Y). Install the actual fan with its marked airflow arrow facing outdoors. If the fan is reversed for intake, the rain louver is on the suction side and the room-side entry shape is on the discharge side; airflow and weather behavior should then be measured again. The louver is optional because any guard or rain baffle adds pressure loss. Select the actual fan from its pressure–flow curve and test the assembled unit; nominal free-air CFM will overstate flow once the guard, louver, window pressure, and any screen are present. A screen added directly to the fan can further reduce performance. Do not operate with an insulated cover installed.

The design follows [AMCA's guidance on smooth, unobstructed inlets and outlet system effects](https://www.amca.org/educate/articles-and-technical-papers/amca-inmotion-articles/mitigating-system-effect-to-optimize-fan-performance-efficiency.html) and [ebm-papst's guidance that guards and obstructions reduce axial-fan performance](https://www.ebmpapst.com/us/en/support/faq.html). The revised dimensions are geometric changes, not a tested airflow or noise rating.
The printed open guard is not certified finger protection; use a rated guard where access to the blades is a concern.

## Insulation design

The deep opening in each wide solid or filler panel is a **foam pocket during assembly**. Cut rigid closed-cell foam to the **Foam cut list**, insert it against the 4 mm front skin, and screw on the printed back skin with thin closed-cell gasket tape at the rim. Every wide cassette gets that closing skin even when the no-foam option is selected; the latter leaves a sealed air cavity with lower insulation performance. The exploded matrix shows the cut foam core separately from the printable shell and back skin. Fillers narrower than 40 mm remain solid because their cavity would be too narrow for a useful insert. The controller blank above the electronics bay uses the same cassette. The controller lid is solid, and the outer end caps have no open wire bores.

Seal the room-side module joints after assembly and use compressible weatherstripping around the window perimeter. Route any external wiring through a properly sealed cable gland sized to the actual harness. Keep exterior water draining outward. These air seals matter as much as the foam core: gaps allow air movement around the insulation. [DOE continuous-air-barrier guidance](https://bsesc.energy.gov/energy-basics/continuous-air-barrier-exterior-walls)

The fan passage must remain open when ventilating. For fan-off periods, each fan gets a separate room-side shell and full back skin around a foam core. Two top hooks engage keyhole pockets in the fan housing; two captured bottom magnets close against sized countersunk steel strike discs secured by M3 screws. Insert magnets and the printed spacers before bonding the cover shell to its back skin. Seal that seam and apply gasket tape around the back-skin perimeter. The configurator adjusts magnet and strike dimensions, pocket clearance, hook clearance, and compressed gasket thickness. **Remove covers before running fans.** The print kit includes the shells, back skins, and magnet spacers; magnets, steel strike discs, foam, and gasket material are purchased separately. The JSON lists hardware counts. Choose screw lengths for the actual printed parts.

The practical high-performance core is cut-to-fit rigid foam, with the air seal at the cassette seams, fan-cover gasket, module joints, and window perimeter. Foil-faced polyisocyanurate has higher nominal R-value per inch than common EPS or XPS; XPS can be more moisture-tolerant. A vacuum insulation panel has far higher nominal R-value but is easily damaged by cutting or fasteners, making it a poor match for custom small modules. These are material comparisons, **not an R-value rating of the finished assembly**. See [DOE air-barrier guidance](https://bsesc.energy.gov/energy-basics/continuous-air-barrier-exterior-walls), [DOE foam-board comparison](https://www1.eere.energy.gov/buildings/publications/pdfs/building_america/guide_insulating_sheathing.pdf), and [ORNL vacuum-panel research](https://www.ornl.gov/publications/long-term-performance-of-vacuum-insulation-panels-integrated-into-building-components/).

## Native OpenSCAD

```bash
make parts FILLER_W=80 PANEL_W=140 TRIM_H=20 DEPTH=55 SASH_SLOT_W=22 SASH_ENGAGEMENT=10
make preview FAN_COUNT=3 ROW_COUNT=2 FILLER_W=80 DEPTH=55
```

For direct Makefile exports, set `DOVETAIL_CLEARANCE` and `PIN_CLEARANCE` as needed and run `make clean` before regenerating an existing set with new values. The web generator keys its STL cache by both clearances automatically.

The Makefile generates individual templates and a legacy all-fan assembly preview. Use the web generator for mixed fan/solid patterns, multiple side panels, exact top rail sections, and the complete quantity list. `top_rail` can also be generated directly with `-D 'part="top_rail"' -D 'panel_w=140' -D 'trim_h=20' -D 'frame_depth=55' -D 'sash_slot_w=22' -D 'sash_engagement=10' -D 'rail_edge="middle"'`. Edge choices are `left`, `middle`, and `right`.

## Installation and electrical notes

This is a design prototype, not a certified window appliance. Provide secure sash retention, rain protection, insect screening, strain relief, and weather sealing for the actual opening. The top rail and alignment pegs are not clamps. Check dovetail fit with a small test print; the default radial clearance is 0.3 mm. A 140 mm module fits a K1 Max by footprint, but check the actual print orientation and depth. PETG or ASA is preferable to PLA in a hot sunny window.

The angled output louvers shed direct rain but are not a weatherproof shutter or thermal seal. Test the sash channel, foam cassette, and fan-cover gasket with short samples before printing a full kit. Check the closed controller bay's electronics temperature under load; move heat-producing electronics to a separate weatherproof enclosure if needed. Inspect for condensation and keep water draining outward.

The controller bay has generic standoffs, not an ESP32-specific footprint. Keep electronics weatherproof. Use a suitably rated fused 12 V supply and a regulator for the ESP32. For 4-wire PWM fans, use an open-collector or open-drain driver near 25 kHz with common ground. Do not route motor power through GPIO.
